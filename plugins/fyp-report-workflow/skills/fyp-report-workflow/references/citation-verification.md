# 引文核验：先定位，后使用

任何一句带引用的论断，动笔前必须先在 `Reference` 下对应 PDF 里找到承载它的原句，并记下位置。找不到原句，就没有资格写。

## 为什么单独定这一条

2026-11 的全量核对发现：书目条目真实，数字也对，但正文里仍有六处结论在 PDF 里查不到。原因是写的时候用的是 catalogue 与 deep analysis 的转述，不是原文。转述会漂移，把「作者认为」「某研究表格里的一行」「综述的总结」混成一句漂亮话。所以判据只能是 PDF 原句。

## 每条论断要记的四件事

1. 文件名：`Reference` 下该 PDF 的完整文件名。
2. 位置：页码，或章节号（摘要、第 3 节、表 2、第 5 节结论）。
3. 原句：英文原句，逐字摘录，不改写、不压缩。
4. 边界：这句话最多能写成什么。样本多大、是相关还是因果、是作者自述还是综述转述别人的研究。

四项缺一，这条引用不许进正文。

## 三步操作

1. 定位。在 PDF 里搜术语，读够上下文，确认读到的是一句能承载该结论的话，而不是关键词命中。
2. 判定。原句与打算写的句子逐项比对：方向是否一致，强度是否一致，对象是否一致。任一项不一致，改写到原句支持的范围。
3. 记录。把四项写进本次交付的中文说明。多条引用做成表格：正文句、PDF 与页码、原句、边界。

## 三种不合格情况，各有固定处理

- 原句只支持更弱的结论：把句子降级到原句范围，不保留原来的强度。
- 原句说的是另一件事：删掉这句，或换一篇真的说过这件事的文献。
- 原句在综述里是转述他人：写成「该综述报告……」，同时核对被转述的研究是否真有该结论；能核到原始研究的，用原始研究。

## 书目按同一标准

- 作者人数、姓名、标题、刊名、卷期页取自 PDF 首页或运行页眉，不取自 catalogue，也不沿用上一版书目。
- 三位以内列全作者；四位及以上，文内用 et al.，参考文献表列全。
- 标题必须是这份 PDF 的标题。若某个标题在 PDF 里查不到，直接换掉，不留「看起来合理」的名字。

## 已知的失效模式

| 模式 | 本轮实例 | 后果 |
|---|---|---|
| 把综述表格里的一行当成综述结论 | Kassenkhan 的「参与增益很少转为显著学习增益」 | 结论比原文宽，方向还被写反 |
| 把设计说明写成结果 | Renzella 的「减少卡住时间」 | 原文根本没有这个发现 |
| 自己补一层因果机制 | Ma 的「学生感到对模拟学习者负责」 | 原文只说 confidence 与 engagement |
| 作者人数凭印象 | Karnalim 判成单作者 | 上一轮把对的改错，标题也随之虚构 |
| 书目标题写成看起来合理的名字 | Karnalim 条目写成 Online Python Tutor 加一个不存在的期刊 | 属于查不到的伪造级错误 |
| 只给结论不给边界 | Jin 的「受限优于不受限」 | 原文是 formative study，不是两组对比 |
| 只核数字不核句子 | 数字全部命中，仍有六处结论无据 | 数字对不等于结论对 |

## 与工具的关系

- `scripts/check_report.py` 只查结构、em dash、缩写与人称，不查引用真伪。它通过不等于引文核验完成。
- 核验靠全文检索：先把 `Reference` 下每份 PDF 抽成纯文本，再逐条回查。抽取与检索的做法写进交付说明即可，脚本不必入库。
- 数字层与语义层分开查：先回查数字串是否出现，再回读承载结论的长句。数字命中只是第一关。
